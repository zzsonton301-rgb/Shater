# شاطر للفواتير

تطبيق Android Native لإدارة المبيعات والمشتريات والمخزون والديون، مكتوب **بالكامل بلغة Kotlin** باستخدام Jetpack Compose وRoom.

## التشغيل

1. افتح المجلد في Android Studio Ladybug أو أحدث.
2. تأكد من استخدام JDK 17.
3. نفّذ `./gradlew :app:assembleDebug` ثم شغّل التطبيق على جهاز Android 8.0 أو أحدث.

## البنية

- `data/Models.kt`: كيانات Room وواجهات DAO وقاعدة البيانات المحلية.
- `ui/ShaterApp.kt`: واجهة Compose العربية RTL والتنقل بين الصفحات.
- `ui/ShaterViewModel.kt`: تدفقات البيانات من Room إلى الواجهة.
- `util/BarcodeScanner.kt`: محلل ML Kit للباركود، مع دعم حقل الإدخال اليدوي في شاشة المادة.
- `util/ExternalActions.kt`: واتساب وتوليد/مشاركة PDF.
- `util/Notifications.kt`: قناة وإشعارات نقص المخزون والعمليات ومواعيد الديون.

## نقاط التوسعة الإنتاجية

- شاشة المبيعات/المشتريات تنشئ `Invoice` و`InvoiceLine` داخل Transaction وتستدعي `adjustQuantity` لتحديث المخزون.
- عند حفظ عملية، استدعِ `Notifications.show(context, ...)` لإشعار البيع أو الشراء.
- استخدم `openWhatsApp` للتذكير بالديون أو إرسال تفاصيل الفاتورة.
- استخدم `createInvoicePdf` ثم `sharePdf` لزر التحميل/الطباعة والمشاركة.
- تطبيق النسخ الاحتياطي يمكنه تصدير ملف قاعدة البيانات عبر Storage Access Framework أو WorkManager إلى خدمة التخزين التي يختارها المستخدم.
- التحليل الذكي يحتاج مزود LLM مصادقاً عليه؛ يجب إرسال بيانات مجمّعة وغير حساسة فقط، مع إضافة شاشة موافقة وإعدادات الخصوصية قبل الربط.

## ملاحظات

هذا الإصدار هو هيكل قابل للبناء والتوسعة، ويضع جميع الصفحات المطلوبة ونماذج البيانات ونقاط التكامل الأساسية دون ربط بخدمة خارجية أو حساب سحابي.
